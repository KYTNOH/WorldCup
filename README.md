# WorldCup
World Cup 2026 Game Tracker
A complete, single-file web app to track all 104 games of the 2026 FIFA World Cup.
Features
All 72 group stage games pre-loaded with dates and matchups
All 32 knockout round slots (Round of 32 through Final)
Live standings recalculated as you enter scores (Points, W/D/L, GF, GA, GD)
Knockout bracket with auto-populated team names from group results
Tournament summary with top scoring teams and goal statistics
All data saves automatically in your browser (no server needed)
How to use
Open `index.html` in any web browser — no installation needed
Enter scores in the Group Stage tab as games are played
Standings update automatically in real time
Switch to Knockout tab to enter elimination round scores
Tournament tab shows overall stats and results
Hosting on GitHub Pages
Create a new repository on GitHub
Upload `index.html` (this file)
Go to Settings → Pages → Source: Deploy from branch → main → / (root)
Your tracker will be live at `https://yourusername.github.io/your-repo-name`
Tournament Format
48 teams, 12 groups of 4
Top 2 from each group + 8 best 3rd-place teams → Round of 32
June 11 – July 19, 2026 across USA, Canada, and Mexico
Final at MetLife Stadium, East Rutherford, New Jersey
